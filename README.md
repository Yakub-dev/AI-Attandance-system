# AI Attendance System 🎓🤖

An AI-powered attendance system that uses facial recognition technology to mark attendance automatically and efficiently. This project reduces manual effort and ensures accuracy in attendance tracking, making it ideal for educational institutions and organizations.

## 📌 Features

- 🧠 Face Detection and Recognition using OpenCV and Machine Learning
- 📷 Real-time webcam integration for live attendance marking
- 🗂️ Student Data Management
- 📊 Attendance Records with Date & Time Stamping
- 🌐 Web-based Interface for admin control
- 🔒 Secure and reliable data handling

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript (optional: Bootstrap for styling)
- **Backend:** Python (Flask/Django)
- **Libraries:** OpenCV, NumPy, Pandas, face_recognition
- **Database:** SQLite / MySQL
- **Others:** Git, GitHub, VS Code
